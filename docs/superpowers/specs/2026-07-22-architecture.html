Why one client can never see another's assets

Isolation isn't the UI hiding things — it's two independent server-side locks, both keyed on the tenant_id in the signed-in token. Even a bug in one is caught by the other.

🔒 Lock 1 — the database RLS

Every row query is filtered by tenant_id = token.tenant_id inside Postgres. If code forgets to filter, the database still returns nothing. A tenant literally cannot read another tenant's rows.

🔒 Lock 2 — the asset proxy prefix

Every file request must sit under tenants/<your id>/. Ask for another tenant's key and the proxy returns 403 — before S3 is ever touched.
