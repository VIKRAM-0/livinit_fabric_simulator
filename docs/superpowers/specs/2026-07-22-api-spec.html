Supabase-handled

One rule for all custom endpoints: the handler's first line calls _lib/auth — verifies the session token, derives tenant_id + role. Browser-supplied tenant ids are never trusted. No session → 401; wrong tenant/role → 403. All requests send Authorization: Bearer <token>.

Identity & session

Supabase — no build

Handled by Supabase Auth via its SDK — we configure, not build. The claims hook is what makes every later request tenant-aware.

SDKauth.signInWithPasswordLog in a user›
AccesspublicHandled bySupabase

Consultant or staff signs in. Google/Apple use signInWithOAuth instead. Returns a session; the app stores it and reads the claims.

Request (SDK)
{
  "email": "priya@acme.com",
  "password": "••••••••"
}
Response session
{
  "access_token": "eyJhbGciOi...",   // JWT
  "refresh_token": "v1.Mx...",
  "expires_in": 3600,
  "user": { "id": "9f2c...", "email": "priya@acme.com" }
}
HOOKcustom access-token claimsStamp tenant_id + role›
AccessinfraRunson every token issue

A Supabase hook reads the user's row in memberships and writes two claims into the JWT. Every custom endpoint reads these — this is the backbone of tenant isolation.

Resulting JWT claims
{
  "sub": "9f2c...",              // user id
  "email": "priya@acme.com",
  "tenant_id": "ac001-...-uuid", // which client
  "role": "client",             // client | staff
  "exp": 1753142400
}

AccessclientInputquery ?key=

Streams a file from S3, keeping AWS keys server-side. New guard: the key must be under tenants/{tenant_id}/ or shared/.

Accessclient

The tenant's balance and plan; surfaces the render counter in the header.

Response 200 — BillingSnapshot

  "tenantId": "ac001-...",
  "plan": "pro",
  "credits": { "balance": 480, "included": 500 },
  "renderCount": 20,
  "renewsAt": "2026-08-01"
}
POST/api/billing/consumeDeduct a credit›
AccessinternalCalled byAI gateway, not the browser

Deducts credits for a render / vision call and returns the updated snapshot. If the balance is 0, the AI call is refused with 402.

Request
{
  "tenantId": "ac001-...",
  "kind": "render",     // "render" | "vision"
  "units": 1
}
Response 200
{ "credits": { "balance": 479, "included": 500 }, "ok": true }
